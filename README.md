# TDT4120 — Algoritmer og datastrukturer

Interaktiv studieguide for [TDT4120](https://www.ntnu.no/studier/emner/TDT4120)
ved NTNU: **[algdat.martinsundal.no](https://algdat.martinsundal.no)** — moduler med quiz, flashcards,
formelsamling og begreper.

Bygget på [StudyCompanion](https://github.com/MartinSA04/StudyCompanion);
dette repoet inneholder kun innhold (`content/`).

## Kjør lokalt

```bash
pnpm install
pnpm dev
```
