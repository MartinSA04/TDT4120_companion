# TDT4120 Algoritmer og datastrukturer

Interaktivt kompendium i [TDT4120](https://www.ntnu.no/studier/emner/TDT4120) ved NTNU:
moduler med quiz, flashcards, formelsamling og begreper. Les det på
**[algdat.martinsundal.no](https://algdat.martinsundal.no)**.

Bygget på [StudyCompanion](https://github.com/MartinSA04/StudyCompanion);
dette repoet inneholder kun innhold (`content/`).

## Kjør lokalt

```bash
pnpm install
pnpm dev
```
